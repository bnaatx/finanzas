# Mis Finanzas

App personal de finanzas (ingresos, gastos, gastos fijos, cajitas y metas). Se instala en el iPhone desde Safari con "Agregar a pantalla de inicio".

- Los datos viven en Supabase (tablas `fin_*`), protegidos con inicio de sesión. Cada persona ve solo lo suyo; solo las metas conjuntas se comparten.
- Las cajitas de Blu y Hornea2 se leen de sus apps (solo lectura).
